# 🍽️ Sistema de Pedidos da Cantina FIAP

Projeto desenvolvido para a disciplina de Engenharia de Software — 3º ano de Engenharia de Computação.

---

## 📌 Descrição do Problema

Nos intervalos entre aulas, alunos enfrentam filas e demora no atendimento da cantina, gerando perda de tempo e falta de organização dos pedidos.

Além disso, o controle manual dificulta a visualização do status dos pedidos e aumenta a chance de erros.

---

## 💡 Solução Proposta

Desenvolver um sistema em Python para gerenciamento de pedidos da cantina FIAP, permitindo:

- Cadastro de pedidos
- Visualização dos pedidos
- Atualização de status
- Cancelamento e edição
- Busca por nome
- Seleção de itens a partir de um cardápio

---

## 🔁 Evolução do Checkpoint 1

Este projeto evoluiu em relação ao Checkpoint 1 com as seguintes melhorias:

- Inclusão de **cardápio estruturado**
- Adição de **preço dos produtos**
- Inclusão de **quantidade**
- Cálculo automático do **valor total**
- Melhor organização dos dados no JSON
- Melhor validação de entradas
- Interface mais clara no terminal
